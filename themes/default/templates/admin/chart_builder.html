怎么做一张好图

  1. 先上传 CSV/JSON，或用一句话描述目标。
  2. 在表格里检查/修正数据，选择 X 与 Y 字段。
  3. 切换图表类型、配色和堆叠，观察中间预览。
  4. 保存后，读者看到的是同一份 spec + 最新数据。

数据最多 1000 行、40 列；上传文件最大 1 MiB。SQL/HTTP 需要配置相应的白名单。
