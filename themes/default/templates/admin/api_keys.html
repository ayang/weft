安全说明

  • Key 只以 SHA-256 哈希形式存库；页面和日志都不会回显完整 Key。
  • 撤销立即生效。删除文章、发布文章也会写入审计日志。
  • 外部 Agent 应通过 WEFT_API_KEY 环境变量读取，不要写进仓库或提示词。
  • 写接口使用 expected_updated_at 做乐观锁，避免覆盖人工编辑。
